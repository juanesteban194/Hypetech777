# Estándar de fotografía

Fuente: [PROMPT_MAESTRO §4.6](PROMPT_MAESTRO.md). Este estándar también se muestra como ayuda en el
formulario de carga del panel de administración (fase 6).

## Toma

- Fondo gris claro liso y luz difusa.
- Misma distancia y mismo encuadre en todas las piezas.
- Lado mayor de la foto original de al menos **1600 px**.

## Proporción

| Sección    | Proporción |
| ---------- | ---------- |
| Ropa       | 4:5        |
| Tecnología | 1:1        |

## Orden de las fotos

1. Frente
2. Espalda
3. Etiqueta de marca y talla
4. Detalles
5. Defectos (**obligatoria si existen**)
6. Puesta (opcional)

El tipo de cada foto (`main`, `back`, `label`, `detail`, `flaw`, `worn`) se marca al subirla.

## Formatos y fondo

- Se aceptan JPEG, PNG, WebP y AVIF. PNG y WebP pueden tener transparencia (recortes hechos fuera
  del sistema).
- Toda foto se muestra sobre `--vitrina` (`#ECECEE`) en ambos temas, por fidelidad de color.
- El texto alternativo (`alt`) es obligatorio al subir cada foto.

## Nunca

- Descargar imágenes de internet ni usar fotos de catálogo de las marcas.
- Poner texturas, ruido o retículas sobre una foto de producto.
